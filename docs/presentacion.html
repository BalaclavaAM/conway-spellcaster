La idea en tres celdas

Conway de verdad

40×24 celdas toroidales con la regla clásica. Cada paso de Clawd avanza una generación. Si la celda a la que se mueve amanece viva, muere.

B3una celda muerta con 3 vecinas naceS23una viva con 2 o 3 vecinas sobrevive

Lenguaje natural

No colocas patrones a mano. Escribes «lanza un proyectil hacia la derecha» y Claude Haiku 4.5 elige un patrón del grimorio, la posición y la dirección. El juego lo estampa.

~1.6 slatencia medida por hechizo1..7modo teclado sin red, por si acaso

Presión constante

La población tiene que quedarse entre 10 y 60. Dos turnos fuera de rango y el reactor explota. Tienes 24 turnos, y la salida está sellada por un patrón inmortal.

tub4 celdas estables que solo un hechizo rompeGLaDOSla IA comenta cada jugada con acidez

El truco técnico

El modelo nunca calcula celdas. Pedirle coordenadas exactas de un glider orientado es justo donde los modelos fallan, y un glider con una celda mal puesta muere en dos generaciones. En vez de eso, la llamada usa tool_choice forzado a una sola herramienta, así que la respuesta siempre es una llamada de función válida, nunca texto libre.

  1. El juego resume el tablero en 400 caracteres: héroe, salida, población y las cajas de las colonias. Nunca las 960 celdas.
  2. Haiku devuelve spell de un enum de 7, más posición, dirección y un comentario de una frase.
  3. El juego valida, rota el patrón canónico de LifeWiki hacia la dirección pedida y lo estampa.
  4. Timeout de 4 s. Si la API falla, entra el fallback por teclado con el mensaje «Reactor offline. Improviso.»
// tool cast_spell · input_schema
{
  spell:   enum [glider, lwss, block, beehive,
                blinker, r_pentomino, eater],
  x:       int 0..39,
  y:       int 0..23,
  dir:     enum [N, E, S, W],
  comment: string  // ≤ 90 chars, estilo GLaDOS
}

// tool_choice: { type: "tool", name: "cast_spell" }
// model: claude-haiku-4-5 · max_tokens: 200

Un CLAUDE.md escrito antes de la primera línea de código: firma de cada función, forma del estado, nivel determinista, paleta y nombres exactos de los assets. Cada card es dueña de archivos distintos, así que siete agentes escribieron a main al mismo tiempo sin un solo conflicto.

Todo módulo funciona sin sus vecinos y sin sus assets. El juego corre sin API key, sin sprite y sin música, y cada pieza que llega lo mejora. Eso es lo que permitió que el arte y el código avanzaran en paralelo sin hablarse.

Juan dirigió a los agentes y escribió el contrato con Claude. Pedro produjo los 21 archivos de arte y sonido. Los agentes escribieron el código, los tests y hasta el guion de demo, verificando la corrida ganadora con Playwright contra el juego real.

Guion de demo, 3 minutos

Nivel fijo, así que esto se puede ensayar. Tres al oeste con wrap, nueve al norte, un R-pentomino que rompe el tub, dos al oeste hasta la salida.

AAA· WWWWWWWWW· 6· AA

Para el momento con la API: parar en la columna 39 y escribir «haz estallar la salida» en la consola en lugar de pulsar 6. Hay un LWSS cruzando la fila 16 alrededor de la generación 20, así que no conviene demorarse.

Si la API tarda, el wifi de la sala falla o no hay key, no hay pausa: el juego sigue con las teclas 1 a 7 y el log dice «Reactor offline. Improviso.». La secuencia de la izquierda no toca la red.

Antes de subir al escenario: abrir el juego en Chrome, pasar el tutorial una vez para que la key quede en localStorage, pulsar F y confirmar 120+ FPS, subir el volumen.
